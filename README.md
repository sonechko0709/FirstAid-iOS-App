# Інформаційна система «Перша Допомога» 

Курсовий проєкт з дисципліни **«Бази даних та об'єктно-орієнтоване програмування»**.

**Виконала:** Єсіпова Таїсія, група МП-21.

## Про проєкт
«Перша Допомога» — це мобільний застосунок для iOS, який надає користувачам чіткі, покрокові алгоритми та екстрені медичні інструкції (при термічних опіках, порізах, розтягненнях тощо). Система базується на клієнт-серверній архітектурі.

##  Стек технологій & Архітектура
* **Client-side:** Мова Swift, фреймворк **SwiftUI** для побудови декларативного інтерфейсу з реактивним оновленням стану (використано сучасний макрос `@Observable`).
* **Back-end as a Service:** Платформа **Supabase**.
* **Database:** Реляційна СУБД **PostgreSQL**. Модель даних спроєктована у третій нормальній формі (**3NF**).
* **Паттерн:** **MVVM** (Model-View-ViewModel).
* **Обмін даними:** Асинхронні запити (`async/await`) через RESTful API.

##  Структура репозиторію
* `/FirstAidApp` — сирцевий код iOS-застосунку (View, ViewModel, DTO-моделі).
* `init_database.sql` — SQL-скрипт для створення структури БД (таблиці `guides`, `guide_steps`, `aid_points`, перерахування `ENUM`) та заповнення її демонстраційними даними.

##  Як розгорнути проєкт
1. **База даних:** Створити проєкт на Supabase, скопіювати вміст файлу `init_database.sql` в *SQL Editor* та натиснути *Run*.
2. **Мобільний клієнт:** Відкрити папку проєкту в середовищі **Xcode** (потрібен macOS) та запустити на симуляторі iPhone.
